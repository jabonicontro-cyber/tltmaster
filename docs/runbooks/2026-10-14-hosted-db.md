## 2. Back up first (the free plan has no backups)

```bash
pg_dump "<session pooler connection string>" -Fc -f taviron-$(date +%F).dump
ls -lh taviron-*.dump    # must not be 0 bytes
```

## 3. Apply

```bash
npx supabase db push --dry-run   # should list only the pending files above
npx supabase db push             # answer Y
npx supabase migration list      # every row now shows Local and Remote
```

Verify:

```sql
select 'help tables' as check, to_regclass('public.help_support_requests') is not null as ok
union all select 'every company still production', not exists (select 1 from public.companies where classification <> 'production')
union all select 'none archived', not exists (select 1 from public.companies where archived_at is not null)
union all select 'delete guarded', to_regprocedure('public.platform_company_delete(uuid,text)') is not null;
```

Known hosted risk (stated, not hidden): permanent delete sets `session_replication_role = replica` inside the
function so append-only guards do not block removing the whole tenant. Locally the function owner is a superuser.
If the hosted `postgres` role may not set it, **Delete Permanently** fails with a permission error and nothing is
deleted (one transaction). Archive and restore do not depend on it. Test it on a throwaway practice company first.
Rollbacks: `supabase/rollbacks/20261120000500…` (refuses while anything is archived or practice), `…000400…`.
