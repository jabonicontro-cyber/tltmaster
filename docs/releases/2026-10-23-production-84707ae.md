## G. AI and integrations

- **Ask Taviron:** read-only assistant over the company's operational data through registered `read` tools on the
  server (`src/server/ai/`), permission-checked, pseudonyms instead of names, usage counts only, labelled output.
- **Enabled in Production: no.** No provider key or model set; `EVAL_EVIDENCE` is empty, so the readiness gate keeps
  it off even if a key were added. All tests use a mocked provider; **no real evaluation has been run.**
- **To activate (each an owner decision, docs/AI.md §12/§15):** choose the provider and models, set the server-only
  variables (key, capabilities, models, monthly token limit, rate, timeout, pricing), run `npm run ai:eval` against the
  real model and commit the generated evidence, then switch the capability on. Paid usage starts only then.
